## 6. Site-Wide SEO Issues Identified in the Audit
1. **Improper heading structure (H1/H2/H3)** — inconsistent or missing hierarchy across pages, making it harder for search engines to parse page topic/relevance.
2. **Missing or weak meta descriptions** — some pages have none; others don't clearly communicate page purpose.
3. **Keyword stuffing instead of natural optimization** — the same keywords are repeated excessively in titles, headings, and content instead of using natural variations.

## 7. SEO Recommendations from the Audit
1. One clear H1 per page; structure content with H2/H3 that reflect topic and user intent.
2. Unique meta titles and descriptions per page, with primary keywords included naturally.
3. Prioritize keyword *variations* over repetition — use semantic variants and related terms, keep content natural per Google's quality guidelines.

**Stated guiding principle:** *"Sprinkle keywords naturally, avoid keyword stuffing, and use relevant variations to improve topical relevance and search visibility."*

## 8. Translating This Into Alt-Text Guidance
The source document is about page-level SEO, not alt text specifically — here's how to apply the same logic when auditing/writing `alt` attributes in the codebase:

- **Describe the image first, optimize second.** Alt text's primary job is accessibility — it must accurately describe what's actually in the image. Only fold in a keyword if it's a natural fit for that description.
- **Match keyword cluster to image type:**
  - Clinic/branding/exterior/location photos → Location keywords (Section 4), e.g. *"Autism therapy center at Kondapur, Hyderabad"*.
  - Therapy session / equipment / activity photos → matching Service-Based cluster (Section 2) — e.g. a sensory room photo → "sensory integration therapy," a child writing with assistance → "occupational therapy for kids."
  - Blog/infographic/explainer images → Informational keyword phrasing (Section 3) — e.g. a graphic listing developmental milestones → "signs of autism in children."
  - Doctor/team photos → Child Specialist / Child Psychologist keywords (Section 2) where contextually accurate.
- **Avoid stuffing.** Don't reuse the exact same keyword phrase across every image on a page — that mirrors the "keyword stuffing" issue the audit specifically flagged. Rotate through the synonyms/variations listed within each cluster instead.
- **Don't force it.** If no keyword in the relevant cluster accurately describes the image, write a plain, accurate description rather than shoehorning a keyword in.
- **Weight toward higher-value terms when there's a genuine tie.** When multiple equally-accurate phrasings exist, prefer the ones flagged "Easy" KD with meaningful volume, e.g. *"child specialist near me"* (10,000 vol), *"aba therapy"* / *"sensory integration therapy"* (1,000 vol each), since these carry the best ranking ROI per the audit.
- **Tie to heading structure where relevant.** Since the audit also flagged inconsistent H1/H2/H3 usage, the agent should check that image alt text is consistent with the H1/H2 topic of the section/page the image sits in, rather than introducing an unrelated keyword.
